원리 1 · 피로 신호 차단

아데노신 수용체의 ‘위장 취업’

뇌가 활동하면 피로 물질인 아데노신이 수용체에 결합해 부교감신경을 활성화(휴식 유도)합니다. 하지만 카페인은 아데노신과 입체 구조가 비슷해 수용체에 먼저 결합하여 피로 브레이크를 고장 냅니다.

원리 2 · 교감신경 흥분

동방결절과 노르에피네프린

브레이크가 풀리면 연수(심장 박동 조절 중추)를 통해 교감신경이 흥분합니다. 교감신경 말단에서 분비된 노르에피네프린이 심장의 박동 원천인 동방결절(SA node)을 자극해 박동 주기를 짧게 만듭니다.

원리 3 · 효소와 길항 작용

왜 사람마다 그래프가 다를까?

간에서 카페인을 분해하는 효소(CYP1A2)가 풍부한 둔감형은 카페인을 빨리 해독하고 부교감신경(아세틸콜린 분비)이 심박수를 원래대로 낮춥니다. 반면 민감형은 고박동 상태가 수 시간 지속됩니다.

교사용 구글 사이트 구축 매뉴얼

구글 사이트(Google Sites)에 이 웹 앱을 완벽 구현하는 방법

STEP 1. 구글 사이트에 시뮬레이터 삽입하기 (1분 완성)

  1. Google Sites(구글 사이트 도구) 편집 화면 우측 메뉴에서 [삽입] → [<> 퍼가기(Embed)]를 클릭합니다.
  2. 상단 탭에서 URL 대신 [코드 삽입(Embed code)]을 선택합니다.
  3. 현재 이 파일의 전체 HTML 코드를 붙여넣고 [다음] → [삽입]을 누릅니다.
  4. 삽입된 박스의 가로 크기를 페이지 전체 너비(12칸)로 넓히고 세로 높이를 충분히 늘려주면 반응형으로 깔끔하게 배치됩니다.

STEP 2. 구글 사이트 추천 수업 페이지 레이아웃 구성안

  • 상단 배너: 구글 사이트 테마 색상을 본 웹앱과 동일한 포레스트 그린(#1E4D3B) & 베이지(#F3EDE0)로 지정하면 이질감 없이 하나의 사이트처럼 통합됩니다.
  • 중단 영역: 본 [심박동 시뮬레이션 웹 앱]을 전체 폭으로 배치합니다.
  • 하단 영역: 우측 메뉴의 [삽입] → [설문지(Google Forms)]를 추가하여, 학생들이 웹 앱의 3단계 탭에서 복사한 탐구 보고서를 바로 붙여넣어 제출하도록 연결합니다.
